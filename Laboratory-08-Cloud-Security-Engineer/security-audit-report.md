# Security Audit Report

## Principle of Least Privilege (PoLP)

The Principle of Least Privilege means giving each user only the permissions needed for their responsibilities. This prevents users from accessing files, applications, or cloud resources that are not part of their work. It also helps limit the damage if an account is compromised.

## Attack Surface

The attack surface includes the different entry points that someone could use to access or attack a virtual machine. Examples include open ports, running applications, and network services. Reducing unnecessary entry points helps lower the chances of a successful attack.

## Default Deny Policy

A Default Deny Policy rejects incoming traffic unless the administrator has created a rule to permit it. This approach gives the administrator better control over which connections can reach the server. It also reduces the risk of unwanted access because unknown connections are blocked by default.
