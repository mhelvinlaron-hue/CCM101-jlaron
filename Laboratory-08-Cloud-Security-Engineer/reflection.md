# Mission Reflection

## 1. How does a host based firewall protect a server even if the physical network perimeter is breached?

A host based firewall provides security directly on the server by checking the network connections that reach it. Even if another layer of network protection fails, the firewall can still block traffic that is not permitted by its rules. I learned that having more than one layer of protection makes a server safer.

## 2. Why is managing open ports critical to reducing a server's attack surface?

Managing open ports helps control which services can communicate with other devices. Every unnecessary open port can give attackers another possible way to investigate or target the server. By allowing only the ports needed for the application and administration, I can reduce the number of possible entry points.

## 3. Why is it dangerous to leave a database port, like 3306 for MySQL, open to the public internet?

A publicly accessible database port can expose important information to unauthorized users. Attackers may try to guess login details or exploit weaknesses in the database service. I learned that database connections should be restricted to trusted systems instead of allowing connections from anywhere on the internet.

## 4. How did this mission change your view of how easily a server can be compromised?

This activity showed me that a server can become vulnerable when basic security settings are ignored. Before completing this mission, I focused more on making an application run than on controlling who could access it. Now, I understand that firewall configuration is an important step that should not be skipped when setting up a server.

Having eight completed missions makes my GitHub portfolio look more organized and complete. Each laboratory gave me a chance to practice different tasks and understand more about cloud computing. I feel satisfied knowing that my repository contains examples of my work and progress. Although I still need to improve my skills, these activities have helped me become more confident when working with cloud technologies.
