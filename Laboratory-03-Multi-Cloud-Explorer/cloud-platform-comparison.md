## Guide Questions

**1. Which cloud provider offers the broadest range of services?**
AWS is the provider I would identify as having the broadest service selection. It covers many areas of cloud computing, from virtual servers and storage to databases, security, networking, and application services. Because of this, businesses have many options when building their cloud environment.

**2. Which provider best integrates with Microsoft technologies?**
Microsoft Azure is the most suitable provider for Microsoft environments. It is designed to work closely with Windows Server, Microsoft 365, and Microsoft Entra ID. This makes Azure convenient for organizations that already have Microsoft based systems.

**3. Which provider is strongest in Artificial Intelligence and Kubernetes?**
GCP stands out in AI and Kubernetes. Google developed Kubernetes and provides Google Kubernetes Engine for managing containerized applications. It also has various services for creating, training, and deploying AI and machine learning models.

**4. Which cloud platform would you personally choose and why?**
If I had to choose one, I would select GCP. I am interested in how cloud computing can be used for data analysis and artificial intelligence. I think learning GCP would give me useful experience with tools such as BigQuery, Vertex AI, and Google Kubernetes Engine.
