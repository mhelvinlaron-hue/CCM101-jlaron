# Google Cloud Platform Research

## Overview
Google Cloud Platform, or GCP, is a cloud service platform developed by Google. It provides resources for running applications, storing information, managing networks, processing data, and creating AI based solutions. GCP is well known for technologies related to data analytics, machine learning, and containers.

## Global Infrastructure
Google Cloud has infrastructure distributed across five continents, with 43 regions and 130 zones. This allows users to select locations for their cloud resources based on application requirements, users, and data needs.

## Cloud Management Console
Google Cloud Console is the main web interface for managing GCP services. Users can create projects, deploy virtual machines, configure storage and networking, manage permissions, and monitor their cloud resources.

## Four Core Services

1. **Compute Engine** — Provides virtual machines for hosting applications and server workloads.
2. **Cloud Storage** — Provides object storage for files, backups, media, datasets, and other information.
3. **Virtual Private Cloud** — Provides networking features for connecting and controlling cloud resources.
4. **Cloud IAM** — Manages identities and permissions for users and applications.

## Three Advantages

1. **Strong AI and ML Features** — GCP provides services that support the development and deployment of machine learning applications.
2. **Excellent Container Support** — Google Kubernetes Engine provides a managed environment for running containerized applications.
3. **Powerful Data Tools** — Google Cloud has services that can process and analyze very large datasets.

## Common Enterprise Uses
- Training and deploying machine learning models
- Analyzing large business datasets
- Hosting container based applications
- Building data processing systems
- Developing modern cloud applications
