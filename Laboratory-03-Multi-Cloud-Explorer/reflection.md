# Reflection

**1. Which cloud platform impressed you the most?**
Google Cloud Platform interested me the most because of its focus on artificial intelligence, data analysis, and Kubernetes. I found these areas interesting because they are becoming more important in modern software development. The services available through GCP could also be useful for future technology projects.

**2. What similarities exist among AWS, Azure, and GCP?**
All three platforms provide the main services needed for cloud computing. They have virtual machines, storage, networking, databases, identity management, and tools for containers. Although the names and features are different, they can solve many of the same problems for users and organizations.

**3. How do business requirements influence cloud platform selection?**
A company's requirements have a major effect on which cloud provider should be selected. The organization needs to consider its budget, existing software, security requirements, workload, expected growth, and technical goals. For example, Azure may be a better choice for a company that already uses Microsoft products, while GCP may be more useful for an organization working heavily with AI and data.

**4. What did you learn from acting as a Cloud Solutions Consultant?**
I learned that recommending a cloud platform requires careful comparison. It is important to understand what the client actually needs before choosing a provider. This activity helped me think about cost, scalability, compatibility, and available services instead of focusing only on the name of the cloud provider.

**5. How has your GitHub Cloud Computing Portfolio improved after completing this mission?**
My GitHub portfolio became more organized because I was able to include my research, Linux investigation, cloud comparisons, and client recommendations. It now shows the different tasks I completed during the activity. I also think it demonstrates that I can research cloud technologies and apply what I learned to practical business situations.
