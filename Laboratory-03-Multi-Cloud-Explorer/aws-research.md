# AWS Research

## Overview
Amazon Web Services, better known as AWS, is a cloud platform provided by Amazon. It was introduced in 2006 and gives users access to computing, storage, networking, databases, security, and many other online services. Instead of buying and maintaining physical hardware, organizations can use AWS resources when they need them.

## Global Infrastructure
AWS has cloud infrastructure located in many countries and regions around the world. Its infrastructure is organized into Regions and Availability Zones. This setup allows companies to place their applications in suitable locations and create systems that can continue operating even if one location experiences a problem.

## Cloud Management Console
The AWS Management Console is an online dashboard for controlling AWS services. Users can launch servers, create storage resources, configure networks, manage permissions, monitor services, and check account costs using the console.

## Four Core Services

1. **Amazon EC2** — Provides virtual computing machines that can be configured to run different applications and operating systems.
2. **Amazon S3** — Provides scalable object storage for files, images, videos, backups, and other digital information.
3. **Amazon VPC** — Creates a virtual network where AWS resources can be organized and connected securely.
4. **AWS IAM** — Controls access to AWS resources by managing users, groups, roles, and permissions.

## Three Advantages

1. **Large Service Selection** — AWS has services for many different computing and business requirements.
2. **Scalable Infrastructure** — Resources can be adjusted when the workload becomes larger or smaller.
3. **Worldwide Deployment** — Organizations can operate applications in different geographic locations using AWS infrastructure.

## Common Enterprise Uses
- Running company websites and web applications
- Creating cloud based databases
- Saving important files and backups
- Processing business information
- Building systems that need to handle changing workloads
