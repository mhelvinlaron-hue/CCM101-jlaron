# Microsoft Azure Research

## Overview
Microsoft Azure is Microsoft's cloud computing service, launched in 2010. It allows organizations to use computing resources, storage, networks, databases, and other technologies through the internet. Azure is especially useful for companies that already depend on Microsoft software.

## Global Infrastructure
Azure has a worldwide cloud network with more than 60 regions. These regions give organizations different choices for where they want to deploy their applications and store their resources. Its global infrastructure also helps businesses provide services to users in different locations.

## Cloud Management Console
The Azure Portal is a web based interface for working with Azure. Through the portal, users can create virtual machines, configure networks, manage storage, monitor resources, control user access, and review their subscriptions.

## Four Core Services

1. **Azure Virtual Machines** — Allows users to create virtual servers in the Azure cloud.
2. **Azure Blob Storage** — Used to store large amounts of files and other unstructured information.
3. **Azure Virtual Network** — Provides a private networking environment for Azure resources.
4. **Microsoft Entra ID** — Provides identity services for managing users, authentication, and access permissions.

## Three Advantages

1. **Works Well With Microsoft Products** — Azure can connect with Windows Server, Microsoft 365, and other Microsoft technologies.
2. **Supports Hybrid Environments** — Organizations can connect their existing local infrastructure with Azure cloud services.
3. **Business Friendly Platform** — Azure provides services that can support many common enterprise workloads and applications.

## Common Enterprise Uses
- Hosting Windows and Linux servers
- Managing employee accounts and access
- Supporting Microsoft based business systems
- Connecting local data centers with cloud services
- Running enterprise applications and databases
