# Laboratory Activity 1 – Welcome to the Cloud

## Mission Overview
This activity served as an onboarding exercise into cloud computing
fundamentals. It involved setting up a Linux environment through
KillerCoda, gathering system information, organizing a local workspace,
and building a version-controlled GitHub portfolio to document all lab
activities for the semester.

## Objectives
- Access a cloud-based Linux environment using KillerCoda.
- Explore and navigate the Linux operating system.
- Gather basic system information.
- Organize files and directories using Linux commands.
- Create and maintain a professional GitHub repository.
- Document technical work using Markdown.
- Demonstrate proper documentation practices used by cloud professionals.

## Activities Performed
**Checkpoint 1 – Enter the Cloud**
Launched an Ubuntu 24.04 Playground on KillerCoda, created a new user
(`jlaron`) with sudo privileges, logged into the account, and recorded
the username, working directory, and hostname.

**Checkpoint 2 – Meet Your Environment**
Investigated the Linux distribution, kernel version, CPU info, total
memory, and available disk space, and recorded the findings in
`system-information.md`.

**Checkpoint 3 – Build Your Workspace**
Created the `Documents`, `Notes`, `Reports`, and `Screenshots` folders
in the home directory, then created and wrote `about-me.md` inside the
`Notes` folder.

**Checkpoint 4 – Create Cloud Computing Portfolio**
Created the public GitHub repository `CCM101-jlaron`, cloned it into
the playground, and built the `Laboratory-01-Welcome-to-the-Cloud`
folder structure with the required files.

**Checkpoint 5 – Document the Mission**
Wrote this README and a short reflection summarizing the activity.

**Checkpoint 6 – Capture Evidence**
Collected and organized screenshots of the playground, terminal
sessions, directory structure, and GitHub repository into the
`screenshots` folder.

**Checkpoint 7 – Complete the Mission**
Committed and pushed all final work to GitHub.

## Linux Commands Used
`sudo adduser`, `sudo usermod`, `su`, `whoami`, `pwd`, `hostname`,
`cat /etc/os-release`, `uname -r`, `lscpu`, `free -h`, `df -h`,
`mkdir -p`, `ls`, `cd`, `nano`, `cat`, `touch`, `cp`, `git config`,
`git clone`, `git add`, `git commit`, `git push`

## Skills Learned
- Navigating and managing a Linux environment through the command line.
- Creating users and checking system information using core Linux
  utilities.
- Organizing a professional file/folder structure.
- Writing technical documentation in Markdown.
- Using Git and GitHub to version-control and publish a portfolio.
