# Reflection – Laboratory Activity 1

Going through this first lab activity gave me a good introduction to
what working as a cloud engineer might actually feel like. At first,
navigating the Linux terminal felt a bit unfamiliar, especially with
commands like `lscpu` and `df -h` that I hadn't used much before. But
after running through the checkpoints, I got more comfortable moving
around the file system and pulling system information without needing
a GUI.

Setting up the GitHub repository was also a good refresher on Git
basics — cloning, committing, and pushing changes. I ran into a small
issue where a pasted command left the terminal stuck on an open quote,
which was a good reminder to type commands line by line instead of
pasting large blocks at once.

Overall, this activity helped me see why documentation and a clean
folder structure matter in real cloud engineering work — it's not just
about running commands, but about keeping a record that someone else
(or future me) could follow. I'm looking forward to building on this
portfolio as the semester continues.
