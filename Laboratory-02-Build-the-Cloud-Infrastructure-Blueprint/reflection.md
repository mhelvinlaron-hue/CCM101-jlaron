## Mission Reflection

### 1. Which cloud infrastructure component do you think is the most important? Why?

I think compute resources are one of the most important cloud infrastructure components. Compute resources such as CPU and RAM allow applications 
and services to run. Without compute resources, the other components would not be able to perform useful tasks.

### 2. How does Linux support cloud computing?

Linux supports cloud computing by providing a stable and flexible operating system for servers and virtual machines. In this laboratory, I used Ubuntu 
Linux to check the CPU, memory, storage, networking, and operating system. Linux also provides many commands that help cloud engineers manage and 
monitor infrastructure.

### 3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it helps engineers understand what needs to be created and configured. It also makes it easier to find problems and 
maintain the infrastructure. Good documentation can help prevent mistakes before deploying a cloud system.

### 4. What new skills did you learn during this laboratory activity?

During this laboratory, I learned how to use basic Linux commands to investigate a system. I also learned about cloud infrastructure components and compared 
services from AWS, Microsoft Azure, and Google Cloud. I learned how to create a simple cloud architecture diagram using Draw.io. I also practiced using GitHub,
Markdown files, and Git commands to organize and document my work.

### 5. How has your GitHub portfolio improved after completing this mission?

My GitHub portfolio improved because I now have several documented laboratory activities in one repository. I added files about Linux investigation, cloud 
infrastructure components, cloud provider comparison, and technical documentation. The portfolio now shows my basic skills in Linux, cloud computing, 
documentation, diagrams, and GitHub.

In conclusion, This laboratory helped me understand the basic parts of cloud computing and how they work together. I also gained practical experience using 
Linux and GitHub. With these experience, I'm prepared in the future projects in CCM101.
