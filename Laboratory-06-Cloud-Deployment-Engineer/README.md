# Laboratory Activity 6: The Cloud Deployment Engineer

## Mission Overview

In this laboratory activity, I learned how to deploy a web application using Docker Compose. I used Nextcloud as the application and MariaDB as the database to understand how two containers work together.

## Objectives

- Create a Docker Compose configuration file.
- Deploy Nextcloud and MariaDB as separate services.
- Understand how the application connects to the database.
- Manage containers using Docker Compose commands.
- Document the deployment process in my GitHub portfolio.

## Deployment Commands Executed

| Command | Purpose |
|---|---|
| `docker-compose up -d` | Starts the services in the background. |
| `docker-compose ps` | Checks the status of the containers. |
| `docker-compose logs` | Displays container logs for troubleshooting. |
| `docker-compose down` | Stops and removes the containers and network. |

## Skills Learned

I learned how Docker Compose simplifies the deployment of applications that need multiple containers. I also understood how Nextcloud connects to MariaDB using the database service name. This activity helped me practice container management, configuration, and basic troubleshooting.
